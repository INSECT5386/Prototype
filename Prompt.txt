### 규칙
1. 모든 복합어는 구(phrase) 형태이다.
2. ‘전치수식’을 사용한다.
3. 모든 어근은 그 어떠한 이유나 경우에도 형태가 변하거나 접사가 붙지 않는다.
---
### 예문
* **a mé sling ci na mè reng tu mam seci o tring yung na. :** 나의 추론 행동 물체는 이롭게 분석했다 서로 상호작용하는 정보적인 것들을
---
### 어근 
- mam 무언가의 시작과 초반 또는 과거
- han  무언가의 끝과 후반 또는 미래
- soa 할 수 있다
- sá / sà 그리고 / 또는
- ád / àd 그러나, 하지만 / 또한
- mé / mè -의 / 부사어
- o 목적어
- tu 서술어
- a / i 나 / 나 이외의 모든 것
#### 개념 어근
- se : 어떤 대상에 대한 분석적인 것 또는 측정/검증하는 것
- we : 어떤 대상을 수정/조절하는 것 또는 어떤 대상을 대체하는 모든 것
- pe : 어떤 것을 수용하는 모든 것
- pu : 어떤 것을 방출 또는 전달하는 것
- zi 무언가가 상승 또는 증가하는 모든 것
- su 무언가가 하강 또는 감소하는 모든 것
- ci : 행동, 행위
- na : 어떤 개념, 사물, 대상(-하는 물체)
- yu : 사람, 인간
- di : 빛
- ru : 소리, 파동
- ga : 냄새
- ma : 신체, 육체, 장기

#### 상태 어근
- reng : 인간의 기준에서 좋다 느끼고 윤리, 도덕적인 모든 상태 또는 어떤 것이 다른 것보다 뛰어나거나 안정한 지점에있는 모든 상태 또는 감정
- song : 인간의 기준에서 나쁘다 느끼고, 윤리, 도덕적이지 못한 모든 상태 또는 어떤 것이 다른 것보다 못하거나 불안정한 지점에 있는 모든 상태 또는 감정
- pung : 사회적 또는 물리적으로 다른 것보다 더 뛰어난 크기와 높이
- cung : 사회적 또는 물리적으로 다른 것보다 더 뛰어나지 못한 크기와 높이
- mang : 규칙적이고 일정거나 논리적이고 설득력 있는 상태 또는 모두가 지켜야할 법적이고 일관성 있는 상태
- zeng : 정신적이고 영적인, 주관적이고 심리적인 상태
- tang : 도구적이고 기계적인 상태 또는 수동적인 상태
- seng : 상황에 따라 효율적으로 유연하게 바뀌거나 진화적인 것 또는 자동적이고 습관적인 것
- elang : 학문/교육적인 상태 또는 교과서적으로 정보와 지식의 밀도가 높은 상태
- sling 시간을 따라 직렬적으로 이동하며 인과적인 상태 또는 원인적인 것 또는 어떤 것을 도출하기 위해 순서적, 단계적, 재귀적, 절차적으로 다음 상태로 이동하는 상태
- cling : 공간/차원적/장소적이며 모든 것이 병렬적으로 존재하거나 어떤 원인에 대한 결과적인 상태
- crang : 중심 또는 국소적인 상태 또는 어느 것에 집중되는 상태와 핵심적인 상태
- ong : 물리적이고 물질적이며 실체 또는 에너지가 존재하는 상태
- tring : 서로 연결 또는 결합되거나 섞여 공유되거나 상호작용하는 상태
- tung : 서로 다르거나 차이가 있는 상태
- yung : 정보적이고 기록적인 상태
- dreng : 창조적이고 복원적인 상태
- brung : 파괴적이고 물리적으로 해로운 상태
- aling : 전기적/전자적이거나 전하를 가지는 상태
- cong : 분산적/전역적이거나 지구적/세계적, 우주적인 모든 상태
- sceng : 아주 뜨겁거나 이미 발회하여 가공 불가능한 에너지를 만드는 상태
- rulong : 기체 또는 액체가 흐르는 상태
- grang : 무언가가 이동하거나 움직이는 모든 상태
